ICSLab FPGA Programmer
======================

1. Connect your FPGA board to USB.
2. Power on the board.
3. Open "ICSLab FPGA Programmer.exe".
4. Select your board.
5. Select the .bit file (Browse... or drag the file onto the window).
6. Click PROGRAM FPGA.
7. Wait for "FPGA programmed successfully."

FPGA SRAM : the design runs immediately and is lost when the board is
            powered off (use this during labs).
Flash     : the design is stored on the board and loads at every power-on.

Do not move the program out of this folder: it needs the "backend" folder.
No installation and no administrator rights are needed.

Developed by ICSLab.

FPGA programming backend:
openFPGALoader (independent open-source project, Apache-2.0)
https://github.com/trabucayre/openFPGALoader
See README-licenses.txt and the LICENSES folder.


Troubleshooting
---------------

Board not detected / "Unable to communicate with the FPGA programmer"
  - Check the USB cable (use the PROG/JTAG USB port of the board).
  - Check that the board is powered on (power switch, LED).
  - Click "Detect Board" to see what the computer finds.
  - Try another USB port. Avoid unpowered USB hubs.

Intel USB-Blaster (DE2, DE10 ...) with a yellow mark in Device Manager
  - Lab instructor: click "USB Setup..." > "Install WinUSB driver"
    (see docs\windows-driver.md). Quartus's own driver is not needed.

USB driver issue / "Windows blocks access to the programmer"
  - openFPGALoader needs the WinUSB driver for most programmers.
  - Follow docs\windows-driver.md (ask your lab instructor first:
    changing the driver affects Vivado/Quartus on this computer).
  - Close Vivado Hardware Manager, Quartus Programmer, Gowin Programmer.

Wrong board selected
  - The board name is printed on the board. If unsure, choose
    "Auto Detect / Generic JTAG", click "Detect Board" and use the
    "Possible board" shown in the Status box.

Malformed bitstream / "The bitstream file is not valid"
  - Select the file generated by the FPGA tools (Vivado: *.bit in
    <project>.runs\impl_1\). Do not select project or report files.
  - Check that bitstream generation finished without errors.
  - The bitstream must be built for the FPGA on your board.

JTAG device not found / "The programmer works, but no FPGA answered"
  - Board power is off, or the board's mode/JTAG jumpers are wrong.
  - Wrong board selected (different programmer wiring).

Flash programming failure
  - First program in "FPGA SRAM" mode to check that the bitstream works.
  - Keep the board powered and connected until the end.
  - Some boards need a specific flash file; ask your lab instructor.

Click "Show Details" to see the full openFPGALoader output; copy it when
asking for help.
